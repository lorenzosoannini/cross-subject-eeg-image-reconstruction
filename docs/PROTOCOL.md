# Implementation decisions

The manuscript's final dataset/method/experiment chapters are the reference, with the following explicit author decisions made on 5 November 2026:

1. Keep the additional image alignment of the shared EEG branch during pretraining. Official ZEBRA aligns only the complete branch at that stage; the retained shared alignment is an explicit EEG adaptation.
2. Estimate per-channel mean and population standard deviation over all valid source-training time samples, with a standard-deviation floor of `1e-6`. Reuse the transform on all subjects. This numerical estimator is newly fixed for this copy, rather than recovered from historical run metadata.
3. Use only `E_i → F_s → prior → unCLIP` for neural image conditioning. Remove full-E generation, target calibration/tuning, retrieval/prototype/medoid conditioning, category fallbacks and extra text fusion. Optional captions describe generated images only.
4. Follow the final manuscript's image exclusions: eight training photographs, one source-validation photograph and a different heldout-evaluation photograph per category. Subject 10 is excluded from every task-specific training stage and from normalization/selection.

The new split uses seed 42 and per-category deterministic random streams. Reference IDs are exported; these are reproducible assignments for this repository and are not claimed to recover an unavailable historical three-way manifest. All repetitions of an image share its partition across subjects. The native 200-concept test partition remains outside the study benchmark.

The reference model uses REVE width 1,216; LoRA rank/alpha/dropout 8/16/.05; shared/private bottlenecks 512/256; two branch blocks with eight heads; joint decoder width 1,024; and a shared two-layer, 19-head resampler with 256 visual tokens. Separate complete/shared projectors produce 1,664-dimensional tokens.

Pretraining preserves masked EEG reconstruction, MixCo image alignment of F and F_s with consistent mixed subject targets, subject classification/adversarial supervision, and latent reconstruction/covariance/variance regularization. Downstream preserves the image classification/discrimination, text alignment and blurry-latent auxiliary losses. The image discriminator's inherited partial gradient reversal through attention is preserved; no unreported change to full gradient reversal is introduced.

Epochs, batch sizes, epoch-50 initialization, model dimensions and the main objective weights follow the documented reference. Where exact historical optimizer metadata could not be certified, `config.json` makes the new implementation choices explicit: AdamW, group learning rate `1e-4`, weight decay `.01`, five-epoch LR/regularizer/semantic warm-ups and two initial epochs with LoRA disabled. A single shared LR schedule replaces experimental scheduling options. Downstream freezes the EEG encoder and decomposition, following the original ZEBRA stage convention. These settings are inspectable reference choices, not an assertion of bitwise historical reproduction.

Inference averages F_s embeddings before 20 corrected-DDIM prior transitions; SDXL unCLIP uses 38 steps, zero unconditional image tokens and standard [-1,1] to [0,1] conversion. Encoding/prior batches are 16/4. Refinement uses the ZavyChromaXL v3 checkpoint, a 25-step noise schedule retaining its final 13 levels, CFG 5 and captions from BLIP-2 OPT-2.7B in batches of one. Training image targets use the inherited bicubic shortest-side resize and center crop to 224×224; the blurry-latent grid is 28×28. Evaluation targets use the same 224-pixel crop followed by the original bilinear antialiased resize to 256×256. Outputs are 256×256. Seeds are recorded; the decoder derives image-specific seeds from seed 42 and visual index. Prior sampling uses deterministic seeds per ordered batch, so changing its batch grouping changes samples.

Excluded from this repository: DSN v2/v3 experiments, residual/full-E/transductive training variants, NSD/fMRI encoders and decoders, video-generation workflows, diagnostic notebooks, W&B caches, thesis build artifacts, datasets and checkpoints. Vendored SGM files retain dependency classes required by their image model modules; unused temporal model files and encoder families were removed.

Training and generation CLI entrypoints are single-process. Caption/refinement scripts retain their inherited Accelerate sharding support; the provided runner executes a single process. No historical-checkpoint compatibility adapter is provided: incompatible checkpoints are rejected before loading model weights.
